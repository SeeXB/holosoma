# Superseded Semantic Reward Report

The earlier additive semantic-bonus design has been retired. The active implementation uses equal valid-objective averaging and redistributes the fixed positive Omni tracking budget without per-component or global semantic reward coefficients.

See [`semantic_fixed_budget_reward_report.md`](semantic_fixed_budget_reward_report.md) for the final method, diagnostics, presets, tests, and training command.
